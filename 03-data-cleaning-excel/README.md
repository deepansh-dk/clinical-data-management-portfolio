# 03 · Data Cleaning in Excel

**Skill shown:** discrepancy management, query tracking and data cleaning with Excel.

## Task
Take a raw dataset of 100 synthetic patients with deliberately planted errors, find every discrepancy using the checks from the [DVP](../02-data-validation-plan), log a query for each, and produce a clean dataset.

## Planned contents
- `raw_dataset.xlsx`: data as entered, with planted errors
- `query_log.xlsx`: query ID, subject, form, field, issue, query text, status (open / answered / closed)
- `clean_dataset.xlsx`: data after query resolution
- `findings_summary.md`: number and type of errors found, and which checks caught them

## Excel techniques used
IF/IFS, COUNTIFS, XLOOKUP, conditional formatting, data validation, date functions, pivot tables.

*Status: planned. All data is synthetic.*
